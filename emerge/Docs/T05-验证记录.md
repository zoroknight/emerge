# T05：规模压力测试与物理方案决策

2026-10-02，Unity 6000.4.7f1，Windows 开发包。六组测试全部通过，保留多刚体方案。正常实验室上限仍为 20；压力测试临时使用 30。

## 配置与测试范围

20 / 30 个细胞分别组成长链、环和对称体，使用项目中的核心与纤毛定义、真实刚体、碰撞和关节。每组执行静置 2 秒、持续驱动 20 秒、半秒交替开关输入 20 秒、非均匀强流施力 20 秒、撤去输入和水流后恢复 5 秒。共 20,100 个物理步、402 秒模拟时间，时间步长 0.02 秒。

输入通过 Input System 测试键盘进入实际动作订阅；水流是验证用的力场代理，并非已完成游戏流场。通过 Script 模式加速调用原生 Physics2D.Simulate，施力使用实际执行器代码。每组结束后重复切换编辑 / 游动五次，验证关节清理与速度归零。

预先设置的验收限值保持不变：锚点误差 ≤ 0.25，非相邻细胞穿透 ≤ 0.06，速度 ≤ 16，角速度 ≤ 720°/秒；撤去外力 5 秒后锚点误差 ≤ 0.03、速度 ≤ 0.15、角速度 ≤ 3°/秒；原生物理单步 P95 ≤ 4 毫秒。位置与速度采用 Unity 世界单位。

## 决策与复现

保留每细胞一个 Rigidbody2D 与连接关节的方案，默认刚性连接、32 / 16 次求解迭代。此结论限于当前参数和六种测试结构；T12 若引入真实收缩或柔性连接，须重新执行规模验证。

打开 CellLab 场景，可从 `Emerge > Tests > Run T05 Stress Suite` 启动完整测试（菜单已编译，尚未人工点击验收）。Windows 开发包命令：

```powershell
.\Builds\Windows\Emerge.exe --cell-lab-stress -logFile .\Logs\t05-player.log
```

运行后生成 `Logs/t05-results.json` 和 `Logs/t05-results.csv`，控制台成功标志为 `CELL_STRESS_T05_PASS: retain_multi_body`。测试会清空当前实验室并恢复默认样本，只在编辑器或开发包中可用。
