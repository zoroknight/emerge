## Cell Lab 原型验收目标

先只实现核心与纤毛，不接入饥饿、温度、完整地图和 NPC。

1. 显示核心与纤毛占位图，允许选择、拖拽、旋转和重置。
2. 在合法接触位置建立自由圆周连接，每个细胞使用 Rigidbody2D 和碰撞体，连接使用 Joint。
3. 仅给主核心直连出口选择 WASD 信号，后续细胞自动跟随；按住时沿功能方向推水并施加相反的身体受力。
4. 显示功能方向、身体受力方向、激活状态和运动轨迹，方便理解布局效果。
5. 构造对称推进、偏置转向、长链与闭环，增加到 20～30 个细胞进行稳定性检查。

验收：同样的纤毛数量，仅改变位置、朝向或通道配置，就能重复得到明显不同的平移与旋转；不直接修改身体坐标实现移动；目标规模下持续驱动无不可恢复的抖动或发散。

多刚体方案验证完成后再做营养颗粒与局部流场，验证“纤毛 + 吸收 → 主动滤食”。若物理不稳定，按项目方案的 Day 3 止损规则调整，并明确收缩能力的范围变化。
