# 美术资产替换指南

当前圆形、星形和纤毛尾巴都是占位图，可以替换。细胞类型、半径、颜色保存在数据资源中，选择、拖拽、旋转由脚本处理，不依赖图片名称。

## 替换已有细胞

1. 在 Unity 的 Project 面板打开 `Assets/_Emerge/Prefabs/Cells/CoreCell.prefab` 或 `CiliaCell.prefab`。
2. 将新素材放入 `Assets/_Emerge/Art`，将纹理导入类型设为 Sprite (2D and UI)，中心轴心设为 Center。
3. 替换预制体内各 SpriteRenderer 的 Sprite / Material，或增加视觉子对象。现有 Body、Highlight、Core glow、Cilia tail 均可改造。
4. 保留根对象上的 CellView 组件，确保 Body 和 Selection 引用有效。若替换选中效果对象，重新指定 Selection；它应默认关闭，由代码控制显示。
5. 根对象的局部尺度会按数据半径设置为 `半径 × 2`。将美术主体归一化为局部直径约 1 个单位：例如 256 像素直径的图片可从 Pixels Per Unit = 256 开始，再调整视觉子对象尺度。根对象用于逻辑位置和旋转，不用根尺度修正图片大小。
6. 默认 Body 的颜色会被细胞数据覆盖。使用自带颜色的最终插画时，取消 CellView 上的 Apply Definition Tint，保留图片与 SpriteRenderer 的颜色。
7. 进入 CellLab 的 Play 模式，检查尺寸、中心、纤毛方向、选中圈，以及拖拽和旋转后的效果。

预制体的局部 +X（右侧）目前是纤毛外露方向。替换时保持这个方向，后续推进规则才能与视觉一致。当前点击范围按数据 Radius 判断，T04 的圆形碰撞体也按数据半径生成；装饰可以超出主体，但不会自动扩大点击或物理碰撞范围。

## 数据与逻辑

`Assets/_Emerge/Data/Cells/Core.asset` 和 `Cilia.asset` 管理中文显示名、类型、半径、连接上限、质量、推力和主体着色。只更换图片不需要修改这些逻辑参数。改变半径属于玩法修改，需要重新检查选择范围，同时检查物理碰撞与连接。

可以直接修改现有预制体内部。若创建全新预制体，需要保留 CellView 并在 CellLabController 的 Core Prefab / Cilia Prefab 上重新指定；重新执行 Create T01 Assets and Scene 会绑定默认路径的预制体，因此自定义整套预制体时应同步维护配置脚本。配置脚本会保留已有默认路径预制体，不会覆盖其美术内容。

通过 Unity 编辑器移动或重命名资源，保留 `.meta`，避免 GUID 改变导致引用丢失。整张覆盖原图片也可保留引用，但仍需检查导入尺寸和 Pixels Per Unit。

## 中文字体

游戏打包包含 `Art/Fonts/NotoSansCJKsc-Regular.otf`，来源为 [Noto CJK 官方仓库](https://github.com/notofonts/noto-cjk)，随附 SIL Open Font License 文件。无需依赖玩家电脑安装中文字体。

字体可在 CellLab 的 CellLabPanel 组件上替换 Chinese Font。使用其他字体时同时保存许可文件，并检查文字覆盖、字号和按钮宽度。配置脚本目前绑定上述字体路径，换字体时也要同步调整该路径。

## 连接桥

T03 的连接桥由 CellConnectionsView 根据真实连接生成，目前为线条占位显示。可独立替换这个视图的材质、宽度或生成方式；保持 CellGraph 拓扑不变。材质在 CellLabController 的 Connection Material 引用中配置，须使用随工程打包的显式引用。最终融合膜尚未实现。

## 物理与方向反馈

T04 的 CellView 初始化根对象的 Rigidbody2D 与 CircleCollider2D，视觉子对象仍可独立替换。不要通过修改根尺度或移动碰撞体偏移修正插画；主体尺度由 Radius 统一控制。质量与推力是玩法参数；配置脚本保留已有数据中的数值，只为新数据填初值。

CellMotionView 单独绘制推水 / 反作用力箭头，正式美术阶段可以替换或隐藏。保持纤毛局部 +X 为推水方向，实际身体施力为其反方向。
